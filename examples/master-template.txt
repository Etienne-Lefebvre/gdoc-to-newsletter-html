============================================================
STRONG TOWNS OTTAWA — MONTHLY NEWSLETTER TEMPLATE
============================================================

HOW TO USE THIS TEMPLATE
1. Make a copy of this Google Doc and rename it
   "[Month Year] Newsletter" (e.g. "June 2026 Newsletter").
2. Fill in every block. Leave the [BLOCK]...[/BLOCK] tags
   exactly as they are — the script needs them to find your
   content.
3. Duplicate any block (highlight, event, recap, etc.) as
   many times as needed. Just copy from the opening tag
   through the closing tag.
4. Delete any block or section you don't need this month
   (delete from [SECTION] through the final [/CLOSING-TAG]).
5. Replace placeholder text shown in [BRACKETS].
6. For links, use the normal Google Docs hyperlink feature
   (Ctrl+K). Do NOT type out [text](url) — that's just a
   readability trick used in the reference example file.
7. Images: upload to your image host (Cloudinary or the STO
   website media library), copy the absolute URL, paste it
   into the Image: field.

STYLING TIPS (visual only — does not affect the script)
- Section "Name:" line → Heading 1 (shows in Outline sidebar)
- Block "Title:" line → Heading 2 (shows in Outline sidebar)
- Opening tags like [HIGHLIGHT] → normal text
- Closing tags like [/HIGHLIGHT] → normal text (don't delete!)

LAYOUT REMINDERS
- Layout: optional per-block field. Values: "half" or "full".
  Defaults: HIGHLIGHT/SPOTLIGHT/LEAD/NEWS/IMAGE-ONLY = full,
  EVENT/RECAP = half. Orphan half-blocks auto-promote to full.
- Buttons: add as many "Button: Label | URL" lines as you
  need (max 3). Script picks the matching layout.

For a fully filled-out example, see
"may-newsletter-google-doc-example.txt" in this folder.
